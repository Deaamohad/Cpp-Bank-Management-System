# C++ Bank Management System

A basic C++ bank management system that lets you read, add, edit and delete clients from a local file. Practice OOP project.

**What it does:**
- View all clients
- Add new clients
- Edit existing clients
- Delete clients
- Data is stored in `Clients.txt` (and users in `Users.txt`)

**How to run:**  
Open `BankManagementSystem.sln` in Visual Studio, build and run. The exe will use the txt files in the same folder as the project.

Nothing fancy, just messing around with file I/O and structs.
